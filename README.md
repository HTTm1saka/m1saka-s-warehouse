```bash
题号.exe                    # 运行（Windows）
```

## 学习建议

1. **先读题**，在注释里把思路用自己的话写一遍再敲代码。
2. **样例过了不等于对**，自己想几组边界数据（最大、最小、0）测一测。
3. 卡住超过 20 分钟再看文件末尾的"提示"。
4. 写完后把 `学习笔记` 补全，像 `t1.cpp` 那样记录踩过的坑。
